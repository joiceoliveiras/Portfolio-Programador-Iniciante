# Portfolio-Programador-Iniciante
🐱

Um portfólio pessoal moderno e totalmente responsivo, desenvolvido apenas com **HTML e CSS**.  
Ideal para quem deseja apresentar seus projetos, habilidades e informações profissionais de forma simples e elegante.

## 🚀 Recursos

- Layout moderno e minimalista  
- Seções de **Home**, **Sobre**, **Habilidades**, **Projetos** e **Contato**  
- Design 100% **responsivo** para celular e desktop  
- Desenvolvido apenas com **HTML e CSS puros**

## 🧠 Tecnologias usadas
